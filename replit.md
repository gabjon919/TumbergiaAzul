# Tumbergia Azul

## Executar no Replit

O projeto é um site estático com várias páginas HTML e imagens locais. O workflow `Start application` serve os arquivos na porta 5000 com:

```bash
python3 -m http.server 5000 --bind 0.0.0.0
```

Use o painel **Preview** do Replit para visualizar o site, começando por `index.html`.
